# Shopwise\n\nMVP di un catalogo prodotti con carrello.\n\n## Stack\n\n- Frontend: React 18 con Create React App\n- Backend: Node.js 20+ con API HTTP REST senza dipendenze runtime\n- Container: Docker e Docker Compose\n- Persistenza carrello: localStorage del browser\n- Catalogo: backend in memoria, pronto per essere sostituito con PostgreSQL\n\n## Avvio locale\n\nFrontend:\n\n    npm install\n    npm start\n\nBackend:\n\n    cd backend\n    npm start\n\nApri http://localhost:3000. Il frontend usa l’API su http://localhost:4000; puoi cambiare l’URL con REACT_APP_API_URL.\n\n## API\n\n- GET /api/health\n- GET /api/products\n- POST /api/cart/quote\n\nEsempio:\n\n    { "items": [{ "productId": "coffee", "quantity": 2 }] }\n\n## Docker Compose\n\n    docker compose up --build\n\nIl frontend sarà disponibile sulla porta 3000 e il backend sulla porta 4000.\n\n## Prossimi passi\n\n1. Spostare i prodotti in un database.\n2. Aggiungere test API e test end-to-end.\n3. Introdurre autenticazione solo quando il carrello dovrà essere sincronizzato tra dispositivi.
